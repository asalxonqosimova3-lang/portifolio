# Portfolio sayt (oddiy Node.js)

1. `.env` faylini oching va tenglikdan keyin o'zingizning qiymatlaringizni yozing (qo'shtirnoqsiz, bo'sh joysiz):
   TELEGRAM_BOT_TOKEN=BotFather bergan token
   TELEGRAM_CHAT_ID=sizning chat ID raqamingiz
   Saqlang (Ctrl + S).
2. Botingizga Telegramda bir marta Start bosing.
3. Terminalda shu papkada yozing:  node server.js
4. Brauzerda oching:  http://localhost:3000

To'xtatish: terminalda Ctrl + C.
Rasm: o'z rasmingizni photo.jpg nomi bilan shu papkaga qo'ying.
